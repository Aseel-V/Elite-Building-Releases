# Website videos

The product video and the short feature clips shown on https://elitebuilding.web.app, recorded from the demo
build of the app with made-up data. They are served from here through jsDelivr
(`https://cdn.jsdelivr.net/gh/Aseel-V/Elite-Building-Releases@media-<n>/media/<file>`), so video traffic never uses
the website's Firebase Hosting allowance. Each change gets a new tag (`media-1`, `media-2`, …): tagged files never change.
